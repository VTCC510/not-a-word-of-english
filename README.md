# not-a-word-of-english（一点英语都不会）  <br/>Antigravity反重力汉化插件


> 安全、轻量、零外部依赖的 **Google Antigravity 桌面客户端** 汉化工具。
>
> 支持 **标准中文 / 中英对照 / 英文原版** 右下角一键免重启切换，强制保留斜杠指令原英文，并在终端命令授权等高风险操作处强制展示中英双语对照。

---

## 核心特点

- **极简部署 · 零外部依赖**：无需 `npm install`，纯原生 Node.js 离线运行，规避国内网络超时、PowerShell `npm.ps1` 拦截与第三方依赖风险。
- **右下角悬浮语言切换按钮（可拖动）**：
  - **`标准中文`**：日常界面流畅简体中文，高风险授权与 `/指令` 保留英文；
  - **`中英对照`**：全界面保留中英双语对照，方便核对官方术语；
  - **`英文原版`**：免重启即时恢复官方原始英文界面。
- **原生层 + 渲染层全覆盖**：
  - 主进程通过无侵入 API 代理覆盖顶部原生菜单、动态右键菜单、系统托盘（含动态智能体运行计数）与系统弹窗，不破坏缩放快捷键、WSL 菜单与自动更新回调；
  - 渲染层覆盖主工作台、全套设置页、快捷键页、模型与积分配额面板、自定义配置（技能/规则/智能体/MCP/钩子）、应用市场全部 9 大分类 108 款插件详情与配置页、侧边栏、下拉菜单、Shadow DOM 与输入框提示语；内置抗版本漂移归一化引擎，客户端小版本升级不掉译。
- **四重安全防线**：
  1. **零网络 / 零鉴权侵入**：纯本地展示层替换，零联网请求，不修改登录凭据、配额、计费及二进制主程序；
  2. **指令标识符原样保护**：`/goal`、`/grill-me`、`/teamwork`、`/plan`、`/browser` 等斜杠指令标识符绝不改写，防止破坏底层指令解析；
  3. **终端命令授权与高风险操作强制双语对照**：原始命令行 100% 物理锁定，授权弹窗与 `Turbo` 等高危权限预设强制保留英文原文对照，杜绝因翻译误差误批准危险命令；
  4. **物理免疫沙盒 + 异常自动熔断**：绝不触碰代码编辑器、终端、文件查看器代码区、路径导航、AI 回复正文及内置浏览器打开的外部网页；异常超限自动静默恢复官方英文原版。
- **防覆盖原版备份与无损还原**：基于 SHA-256 哈希指纹独立归档官方纯净原版，绝不用补丁版覆盖原版备份；支持 Antigravity 运行中安全排队换包，随时一键无损还原。

## 快速开始（前置要求：Node.js ≥ 18）

### 方式一：发给 Antigravity 一键部署（推荐，无需找隐藏目录/开任务管理器）

直接复制下面这段话发送给 Antigravity：

```text
请帮我克隆 https://github.com/VTCC510/not-a-word-of-english 到本地，阅读 README.md 并运行 node cli.js install --yes --apply 完成汉化部署。
```

- **首次安装（或官方大版本覆盖后）**：补丁校验就绪后，双击一次项目目录中的 **`启动汉化工具.bat`**——无需输入任何数字、无需去 `AppData` 找脚本、也无需打开任务管理器，它会自动识别刚准备好的补丁、关闭所有前后台 Antigravity 进程并在几秒内自动替换重启。
- **日常升级与更新（v1.0.5 起）**：直接在 Antigravity 中发送上述指令，**客户端窗口内会自动弹出原生【立即重启生效】对话框**，点一下即可 2 秒自动完成全部替换与重启。

### 方式二：下载后双击运行（Windows）

1. 下载本仓库代码并解压；
2. 双击 **`启动汉化工具.bat`**，输入 `2` 并回车，即可自动备份原版、关闭后台残留进程并重启完成汉化。

### 方式三：命令行操作

```bash
# 查看本机 Antigravity 路径、版本与备份健康度（纯只读）
node cli.js status

# 执行安全汉化并立即弹出系统【确定】一键换包重启窗口（推荐）
node cli.js install --yes --apply

# 无需确认，2 秒后直接关闭前后台进程并完成汉化重启
node cli.js install --yes --auto-restart

# 对已暂存的新包触发一键弹窗替换重启
node cli.js apply

# 一键无损还原为官方英文原版
node cli.js restore --apply

# 校验 app.asar 与原版备份的 SHA-256 完整性（纯只读）
node cli.js verify

# 离线校验词典安全规则与脚本语法
node cli.js check
```

> 若客户端安装在非默认目录，可追加 `--path "你的 Antigravity 安装目录或 Antigravity.exe 路径"`。

## 注意事项与风险提示

1. **官方更新会覆盖汉化**：Antigravity 自动更新后会用新版官方 `app.asar` 覆盖本地文件。更新后重新运行 `node cli.js install --yes --apply`（或双击 `启动汉化工具.bat`）即可自动识别新版并归档新的原版备份。
2. **请勿与其他汉化工具叠加**：若本机已安装其他第三方汉化补丁，本工具会自动检测并中止，避免破坏原版备份；请先还原为官方英文原版后再使用本工具。
3. **支持平台说明**：当前已在 Windows 上完整实测验证（适配至 Antigravity 2.35.x）；架构已预留 macOS 路径接口，但 macOS 存在系统签名校验机制，修改 `app.asar` 可能触发系统拦截，暂未提供正式支持。
4. **免责声明**：本项目为社区开源非官方本地化工具，与 Google 及 Antigravity 官方无任何隶属关系。本仓库不分发任何 Antigravity 官方程序文件，仅在用户本地对界面展示文案进行可逆替换。请遵循相关法律法规及软件使用条款，使用本项目产生的风险由使用者自行承担。
